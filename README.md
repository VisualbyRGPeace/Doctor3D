# Doctor3D

Doctor3D là bản thử nghiệm đầu tiên của ứng dụng dựng hình 3D chạy trên trình duyệt, lấy cảm hứng từ cách làm việc trong Blender.

## Chạy ứng dụng

Mở `index.html` trên một máy chủ web tĩnh, hoặc bật GitHub Pages cho repository này. Ứng dụng tải Three.js từ jsDelivr nên cần kết nối Internet.

## Công cụ hiện có

- Tạo khối lập phương, hình cầu, hình trụ, hình nón và hình xuyến.
- Xoay khung nhìn bằng chuột trái, rê khung nhìn bằng chuột giữa và thu phóng bằng con lăn.
- Chọn đối tượng trong khung nhìn hoặc danh sách Cảnh.
- Di chuyển (`G`), xoay (`R`), co giãn (`S`); nhấn `X`, `Y` hoặc `Z` để khóa theo trục rồi nhập giá trị.
- Nhân đôi bằng `Shift+D`, xóa bằng `Delete`; chỉnh vị trí, góc xoay và kích thước trong Thuộc tính.

## Giai đoạn tiếp theo

Đây mới là nền tảng thao tác và tạo khối cơ bản. Có thể phát triển tiếp các công cụ chọn và biến đổi trực quan, lưu/mở cảnh, vật liệu, rồi đến các thao tác chỉnh sửa lưới.
