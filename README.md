# Doctor3D · Ghi chú & Công việc

Web app mini giúp ghi chú nhanh và quản lý việc cần làm, với giao diện trắng–đen tối giản, icon line tinh tế.

## Tính năng

- 📝 **Ghi chú**: tạo, sửa, xóa, tìm kiếm, gắn màu phân loại
- ✅ **Việc cần làm**: thêm, đánh dấu hoàn thành, lọc (tất cả / chưa xong / đã xong), thanh tiến độ
- 🌓 **Sáng / tối**: tự động theo hệ thống, có nút chuyển tay
- 💾 **Lưu offline**: dữ liệu lưu trong trình duyệt (localStorage), không cần mạng hay tài khoản
- 📱 **Responsive**: dùng tốt trên điện thoại và máy tính

## Chạy thử

Mở file `index.html` bằng trình duyệt, hoặc xem qua GitHub Pages sau khi bật Pages cho repo này.

## Cấu trúc

```
index.html   — khung trang
styles.css   — toàn bộ giao diện (sáng/tối)
app.js       — logic ghi chú, todo, lưu trữ
```
